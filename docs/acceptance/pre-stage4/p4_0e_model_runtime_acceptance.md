Acceptance requires an exact clean parent, package/selftest success, focused
`8`, full regression `2104`, exact final scope, and a real network call over a
committed C/C++ sample using the selected endpoint and API-key environment.

The evidence must prove default/override truthfulness, CWD `.env` precedence,
typed missing-credential rejection, stable public provider parameters, separate safe call metadata, legacy non-JSON configuration preservation, role-specific requested/effective reasoning,
DeepSeek Thinking enabled, no secret values, no `.env` contents, no private
reasoning persistence, and no P4-0F+ implementation.

A real provider response is evidence only for transport and the frozen safe
configuration contract. It is not a model-quality, arbitrary-kernel,
optimization-success, or PPA-superiority claim. Stage 4 remains forbidden.
